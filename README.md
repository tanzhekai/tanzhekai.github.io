# tanzhekai.github.io

Personal website of **Tan Zhe Kai**: education, experience, projects, tech stack, and a downloadable resume.

Live at **https://tanzhekai.github.io**

## Files

| File | What it is |
|---|---|
| `index.html` | The whole site: markup, styles and a few lines of script in one file. No build step. |
| `Resume_TanZheKai.pdf` | The resume behind every "Download resume" button. |

## Updating

- **New resume:** replace `Resume_TanZheKai.pdf` with the new PDF under the same name, then change "Updated October 2026" in `index.html`.
- **New project or role:** copy an existing `<article class="entry">` block in `index.html` and edit it. The left column (`.meta`) holds the dates or project type.
- GitHub Pages republishes automatically a minute or so after each commit to `main`.

Fonts: Literata and Schibsted Grotesk, from Google Fonts.
